# `s.removeprefix(p)`

Remove o prefixo exato, se presente.

## Parâmetros

| nome | tipo | default | nota |
|---|---|---|---|
| `p` | str | — |  |

## Retorno

str

## Exemplos

```ps
post("api_nome".removeprefix("api_"))
```

```saida
nome
```

## Bordas

- sem o prefixo, devolve a string intacta
