# `s.contains(sub)`

True se contém a substring (extensão da PoolScript).

## Parâmetros

| nome | tipo | default | nota |
|---|---|---|---|
| `sub` | str | — |  |

## Retorno

bool

## Exemplos

```ps
post("banana".contains("nan"))
```

```saida
True
```
