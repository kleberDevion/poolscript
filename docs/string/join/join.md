# `sep.join(lista)`

Junta os itens da lista com o separador.

## Parâmetros

| nome | tipo | default | nota |
|---|---|---|---|
| `lista` | list de str | — |  |

## Retorno

str

## Erros

- **SomeValueUnexpected** — item não-string

## Exemplos

```ps
post("-".join(["a", "b", "c"]))
```

```saida
a-b-c
```
