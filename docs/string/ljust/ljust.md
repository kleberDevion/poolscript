# `s.ljust(largura, preenchimento=" ")`

Preenche à direita até a largura.

## Parâmetros

| nome | tipo | default | nota |
|---|---|---|---|
| `largura` | int | — |  |
| `preenchimento` | str de 1 char | " " |  |

## Retorno

str

## Exemplos

```ps
post("ab".ljust(5, "-"))
```

```saida
ab---
```
