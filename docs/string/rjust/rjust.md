# `s.rjust(largura, preenchimento=" ")`

Preenche à esquerda até a largura.

## Parâmetros

| nome | tipo | default | nota |
|---|---|---|---|
| `largura` | int | — |  |
| `preenchimento` | str de 1 char | " " |  |

## Retorno

str

## Exemplos

![exemplo 1](../../assets/string__rjust__rjust_ex1.png)

<details><summary>código</summary>

```ps
post("ab".rjust(5, "-"))
```

</details>

```saida
---ab
```
