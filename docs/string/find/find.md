# `s.find(sub, inicio=0)`

Índice da primeira ocorrência, ou -1.

## Parâmetros

| nome | tipo | default | nota |
|---|---|---|---|
| `sub` | str | — |  |
| `inicio` | int | 0 |  |

## Retorno

int
