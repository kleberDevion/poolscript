# `s.find(sub, inicio=0)`

Índice da primeira ocorrência, ou -1.

## Parâmetros

| nome | tipo | default | nota |
|---|---|---|---|
| `sub` | str | — |  |
| `inicio` | int | 0 |  |

## Retorno

int

## Exemplos

```ps
post("banana".find("na"), "banana".find("xyz"))
```

```saida
2 -1
```
