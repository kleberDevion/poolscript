# `s.index(sub)`

Como find, mas ERRA quando não acha.

## Parâmetros

| nome | tipo | default | nota |
|---|---|---|---|
| `sub` | str | — |  |

## Retorno

int

## Erros

- **SomeValueUnexpected** — substring ausente

## Exemplos

```ps
post("banana".index("na"))
```

```saida
2
```
