# `s.center(largura, preenchimento=" ")`

Centraliza preenchendo dos dois lados.

## Parâmetros

| nome | tipo | default | nota |
|---|---|---|---|
| `largura` | int | — |  |
| `preenchimento` | str de 1 char | " " |  |

## Retorno

str

## Exemplos

```ps
post("ab".center(6, "*"))
```

```saida
**ab**
```
