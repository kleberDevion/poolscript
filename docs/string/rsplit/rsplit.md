# `s.rsplit(sep=Null, maxsplit=-1)`

Como split, mas conta as divisões da DIREITA.

## Parâmetros

| nome | tipo | default | nota |
|---|---|---|---|
| `sep` | str | Null |  |
| `maxsplit` | int | -1 |  |

## Retorno

list

## Exemplos

```ps
post("a,b,c".rsplit(",", 1))
```

```saida
['a,b', 'c']
```
