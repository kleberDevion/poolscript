# `d.contains(chave)`

Apelido de `has` — as duas grafias existem.

## Parâmetros

| nome | tipo | default | nota |
|---|---|---|---|
| `chave` | qualquer | — | a chave a testar |

## Retorno

bool

## Exemplos

```ps
d = { "a": 1 }
post(d.contains("a"), d.contains("z"))
```

```saida
True False
```
