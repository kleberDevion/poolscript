# `l.sort()`

Ordena crescente NO LUGAR (muta).

## Retorno

Null — muta a lista

## Exemplos

```ps
l = [3, 1, 2]
l.sort()
post(l)
```

```saida
[1, 2, 3]
```

```ps
l = ["banana", "abacaxi"]
l.sort()
post(l)
```

```saida
['abacaxi', 'banana']
```

## Bordas

- pra uma CÓPIA ordenada, use o builtin `sorted(l)`
