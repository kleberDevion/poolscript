# `l.has(item)`

Apelido de `contains` — as duas grafias existem.

## Parâmetros

| nome | tipo | default | nota |
|---|---|---|---|
| `item` | qualquer | — | o valor a procurar |

## Retorno

bool

## Exemplos

```ps
post([1, 2].has(1), [1, 2].has(9))
```

```saida
True False
```
