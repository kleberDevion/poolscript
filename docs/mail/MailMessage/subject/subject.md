# `MailMessage.subject(titulo)`

Define o **assunto** (título) do e-mail — a linha que aparece na lista de
e-mails do destinatário.

```
m.subject(titulo: str) -> None
```

---

## Uso

```
m = mail.MailMessage()
m.subject("Sua fatura de julho")
```
