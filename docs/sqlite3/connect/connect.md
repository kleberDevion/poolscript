# `sqlite3.connect(database)`

Abre conexão com banco SQLite. Cria o arquivo se não existir.

## Parâmetros

| nome | default |
|---|---|
| `database` | (obrigatório) |

## Exemplo

```
import sqlite3
r = sqlite3.connect(database)
post(r)
```
