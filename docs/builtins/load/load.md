# `load(path=Null)`

Carrega variáveis de um arquivo .env para o ambiente — atalho de dotenv.load.

## Parâmetros

| nome | tipo | default | nota |
|---|---|---|---|
| `path` | str | Null | Null procura o .env por perto |

## Retorno

bool

## Bordas

- é a MESMA função de `dotenv.load` exposta sem import
