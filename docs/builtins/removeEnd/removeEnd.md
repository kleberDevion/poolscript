# `removeEnd(lista)`

Remove e devolve o ÚLTIMO item da lista.

## Parâmetros

| nome | tipo | default | nota |
|---|---|---|---|
| `lista` | list | — | mutada in-place |

## Retorno

o item removido

## Erros

- **ValueError** — a lista está vazia, ou o argumento não é `list`

## Exemplos

```ps
l = [1, 2]
post(removeEnd(l), l)
```

```saida
2 [1]
```
