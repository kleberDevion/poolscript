# `sum(lista)`

Soma os números de uma lista.

## Parâmetros

| nome | tipo | default | nota |
|---|---|---|---|
| `lista` | list | tup | — |  |

## Retorno

int | flo

## Erros

- **SomeValueUnexpected** — item não-numérico

## Exemplos

![exemplo 1](../../assets/builtins__sum__sum_ex1.png)

<details><summary>código</summary>

```ps
post(sum([1, 2, 3]))
```

</details>

```saida
6
```
