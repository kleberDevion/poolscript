# `sum(lista)`

Soma os números de uma lista.

## Parâmetros

| nome | tipo | default | nota |
|---|---|---|---|
| `lista` | list | tup | — |  |

## Retorno

int | flo

## Erros

- **SomeValueUnexpected** — item não-numérico

## Exemplos

```ps
post(sum([1, 2, 3]))
```

```saida
6
```

## Bordas

- lista vazia soma 0
