# `reversed(lista)`

Nova lista com os itens na ordem inversa; a original não muda.

## Parâmetros

| nome | tipo | default | nota |
|---|---|---|---|
| `lista` | list | tup | — |  |

## Retorno

list

## Erros

- **TypeError** — o valor não é sequência (`str`, `list`, `tup` ou `bytes`)

## Exemplos

```ps
post(reversed([1, 2, 3]))
```

```saida
[3, 2, 1]
```
