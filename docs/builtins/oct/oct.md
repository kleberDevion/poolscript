# `oct(n)`

Inteiro em octal, com prefixo 0o. Inteiro grande também (o sinal vai antes do
prefixo).

## Parâmetros

| nome | tipo | default | nota |
|---|---|---|---|
| `n` | int | — |  |

## Retorno

str

## Erros

- **TypeError** — o argumento não é `int`

## Exemplos

```ps
post(oct(8))
```

```saida
0o10
```
