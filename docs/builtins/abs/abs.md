# `abs(n)`

Valor absoluto de um número.

## Parâmetros

| nome | tipo | default | nota |
|---|---|---|---|
| `n` | int | flo | bool | — |  |

## Retorno

int | flo

## Erros

- **SomeValueUnexpected** — não-número

## Exemplos

```ps
post(abs(0 - 4), abs(2.5))
```

```saida
4 2.5
```
