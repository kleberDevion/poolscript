# `addStart(lista, valor)`

Adiciona um valor ao **início** de uma lista. Modifica a lista original.

```
addStart(lista, valor) -> None
```

---

## Uso

```
fila = ["b", "c"]
addStart(fila, "a")
post(fila)              // ["a", "b", "c"]
```
