# `id(x)`

Identidade do valor: endereço para objetos, o próprio conteúdo para imediatos.

## Parâmetros

| nome | tipo | default | nota |
|---|---|---|---|
| `x` | qualquer | — |  |

## Retorno

int

## Bordas

- dois `5` têm o mesmo id (valor imediato); duas listas iguais têm ids diferentes
