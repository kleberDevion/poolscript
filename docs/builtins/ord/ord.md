# `ord(c)`

Codepoint unicode de um caractere.

## Parâmetros

| nome | tipo | default | nota |
|---|---|---|---|
| `c` | str de 1 caractere | — |  |

## Retorno

int

## Erros

- **SomeValueUnexpected** — string com tamanho diferente de 1
