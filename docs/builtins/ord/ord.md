# `ord(c)`

Codepoint unicode de um caractere.

## Parâmetros

| nome | tipo | default | nota |
|---|---|---|---|
| `c` | str de 1 caractere | — |  |

## Retorno

int

## Erros

- **TypeError** — a `str` não tem exatamente 1 caractere

## Exemplos

```ps
post(ord("A"))
```

```saida
65
```
