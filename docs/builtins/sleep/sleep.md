# `sleep(segundos)`

Pausa a execução pelo tempo dado (aceita fração).

## Parâmetros

| nome | tipo | default | nota |
|---|---|---|---|
| `segundos` | int | flo | — |  |

## Retorno

Null

## Erros

- **TypeError** — o argumento não é `int` nem `flo`

## Bordas

- é sono do processo — nada a ver com async
