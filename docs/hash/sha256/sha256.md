# `hash.sha256(dado)` — resumo SHA-256 em hexadecimal

Calcula o **SHA-256** (RFC 6234) do dado e devolve o resumo já escrito em
hexadecimal. Serve pra **impressão digital** de conteúdo: comparar dois
arquivos, versionar cache, assinar um token.

```
hash.sha256(dado) -> str
```

> **Não é pra senha.** SHA-256 é rápido e não tem salt: a mesma senha dá
> sempre o mesmo resumo, e quem rouba o banco testa bilhões por segundo. Pra
> senha use [`hash.crypt()`](../crypt/crypt.md) + [`hash.check()`](../check/check.md).

---

## Parâmetros

| nome | tipo | default | nota |
|---|---|---|---|
| `dado` | qualquer valor | — | posicional; o motor **não aceita por nome** |

Exatamente **um** argumento posicional. `hash.sha256(dado="a")` é
`TypeError: sha256() takes no keyword arguments` — o nome `dado` aqui é só
como esta página chama a posição 1.

O valor é convertido com `str()` antes de ser digerido, e o texto entra em
**UTF-8**. Então `hash.sha256(123)` é idêntico a `hash.sha256("123")`.

---

## Retorno

**`str`** — **64 caracteres**, hexadecimal **minúsculo** (`0`–`9`, `a`–`f`),
sem prefixo, sem separador e sem quebra de linha. São os 32 bytes do resumo,
dois caracteres por byte.

O tamanho é sempre 64, não importa o tamanho da entrada:

```
import hash

hash.sha256("abc")
# "ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad"

hash.sha256("")
# "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855"

len(hash.sha256("qualquer coisa"))   # 64
```

Não é `bytes`. Se você precisa dos 32 bytes crus, decodifique o hexadecimal
com [`bytes.fromhex()`](../../bytes/fromhex/fromhex.md).

---

## Erros

- **TypeError** — número de argumentos errado:
  `sha256() takes exactly one argument (0 given)`, idem com 2 ou mais.
- **TypeError** — argumento por nome: `sha256() takes no keyword arguments`.

Nenhuma entrada de texto é recusada: string vazia, acento e byte alto passam.

---

## Bordas

- **Acento conta como UTF-8**, não como caractere:
  `hash.sha256("ação")` = `0664077f33cc3ebbaa4bbdacac0eb70e740983080f01dce29929e73b7785a7ad`
  (5 bytes de entrada, não 4).
- **`bytes` não vira conteúdo — vira representação.**
  `hash.sha256(bytes.fromhex("616263"))` **não** é o resumo dos 3 bytes
  `61 62 63`: o argumento passa por `str()` e o que entra é o texto `b'abc'`,
  7 caracteres. Medido: o resultado é igual a `hash.sha256("b'abc'")` e
  diferente de `hash.sha256("abc")`. Pra digerir binário de verdade, converta
  você mesmo pro texto que quer digerir.
- **Determinístico e sem salt** — duas chamadas com a mesma entrada devolvem a
  mesma string. É isso que o torna útil pra cache e comparação, e inútil pra
  senha.
- Lido sem chamar, `hash.sha256` é um valor de tipo `funct`.

---

## Uso: identificar conteúdo sem guardar o conteúdo

```
import hash
import os

conteudo = os.readFile("relatorio.csv")
impressao = hash.sha256(conteudo)      # 64 hex

# baixou de novo? só reprocessa se a impressão mudou
if (impressao != impressao_anterior) {
    post("arquivo mudou")
}
```
