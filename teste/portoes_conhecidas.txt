# Uma por linha, com os campos separados por TAB:
#
#     portão  página  impressão  item  sistema  onde
#
# portão: check (o --check de cada bloco), roda (o bloco rodando, com JIT e
# sem), p2 (cada chamada de cada membro: scripts/confere_checador.pr; a página
# é o membro, `membro:dono.nome`, e a impressão é a do texto da chamada),
# titulo (a assinatura do título de uma página de método contra o motor:
# scripts/audita_doc.pr), p3 (o servidor do editor em cada bloco:
# scripts/confere_editor.pr; a impressão é a do lugar conferido junto do
# bloco), gramatica (a gramática escrita contra o parser:
# scripts/confere_gramatica.pr; a página é também o caso da suíte,
# `suite:casos_<grupo>.c:<caso>`, ou o sorteio, `gerado:<n>`, e a impressão é
# a do que se conferiu junto do programa) ou p4 (a suíte no --check,
# scripts/confere_suite.pr, com a página `suite:...`, e os programas gerados,
# teste/geradores/programas.pr, com a página do achado encolhido,
# `teste/p4_achados/<impressão>.pr`); impressão: os 12 primeiros dígitos
# do SHA-256 do texto do bloco; item: o item aberto de
# notas/CORRECAO-BASE.md; sistema: todos, linux, darwin ou windows; onde: só
# pra quem lê. Falha que não está
# aqui reprova o portão, e linha daqui que não falha mais também reprova
# (consertado: tire a linha e risque o item).
